คู่มือการกรอกข้อมูล คู่กรณี · ผู้บาดเจ็บ · ทรัพย์สิน

ระบบ SE Survey (เว็บผู้ตรวจสอบ + แอปมือถือช่าง) · ฉบับ 21 กันยายน 2569 (ปรับปรุงค่ำ) · ใช้กับบอท se-autokey v1.1.23 ขึ้นไป และแอป APK 1.0.118+120 ขึ้นไป
ทำไมต้องกรอกตามคู่มือนี้ — ข้อมูลทั้ง 3 ส่วนถูกบอทนำไปกรอกเข้าระบบ EMCS ของบริษัทประกันโดยอัตโนมัติ ระบบ EMCS มีช่องบังคับหลายช่อง ใส่ค่าผิดรูปแบบไม่ได้ และบางช่องมีช่องเดียว (เช่น ที่อยู่) ระบบ SE Survey จึงประกอบค่าให้ตรงกับที่ EMCS รับ กรอกตามกติกาแล้วบอทจะไม่หยุดถามระหว่างทาง และหัวหน้าไม่ต้องไปแก้บน EMCS ทีหลัง

1. กติการ่วมทั้ง 3 ส่วน

1.1 ช่องบังคับ (ดอกจันแดง *)

  • ช่องที่มีดอกจันแดงต้องมีค่าเสมอ ว่างไว้ = แอปไม่ให้ส่งงาน / เว็บไม่ให้อนุมัติ (ขึ้น "ยังขาด N ช่อง")
  • ช่องข้อความบังคับที่ ไม่มีข้อมูลจริง ให้พิมพ์ - (ขีดเดียว) — ระบบถือว่า "ไม่ทราบ" และไม่เตือนผิดรูปแบบ
  • ช่องตัวเลข / วันที่ / โทรศัพท์ / ทะเบียน ใส่ - ไม่ได้ (EMCS ปัดตกทั้งไฟล์) → ไม่ทราบให้เว้นว่าง

1.2 คำที่ไม่ควรพิมพ์เอง

อย่าพิมพ์คำว่า "รอตรวจสอบ" หรือ "--" ลงในช่องด้วยตัวเอง — ระบบจะแปลงเป็น - ให้ตอนเข้า EMCS ก็จริง แต่บนเว็บจะดูรกและนับผิดได้ ให้ใช้ - หรือเว้นว่างแทน (คู่กรณีให้ใช้ปุ่มติ๊ก "รอตรวจสอบ" ที่การ์ด ดูข้อ 2.3)

1.3 ชื่อและคำนำหน้า

  • คำนำหน้าเป็นช่องแยก (นาย / นาง / นางสาว / ด.ช. / ด.ญ. / คุณ) ช่องชื่อพิมพ์เฉพาะ ชื่อ นามสกุล
  • ระบบประกอบเข้า EMCS เป็น นาย สมชาย ใจดี ให้เอง · งานเก่าที่พิมพ์คำนำหน้าติดในชื่อยังใช้ได้ ไม่ซ้ำคำนำหน้า
  • ไม่ทราบชื่อ (ผู้ขับขี่คู่กรณี · ผู้บาดเจ็บ · เจ้าของทรัพย์สิน): เว้นว่าง หรือพิมพ์ - ก็ได้ — ระบบกรอกเข้า EMCS เป็น ไม่ทราบชื่อ ให้เอง และไม่ต่อคำนำหน้า (ไม่มี "คุณ ไม่ทราบชื่อ") · เฉพาะผู้ขับขี่รถประกันและ "เจ้าของรถคู่กรณี" ที่ไม่ทราบใช้ -
  • เจ้าของทรัพย์สิน/เจ้าของรถที่เป็นบริษัท: เว้นคำนำหน้าว่าง

1.4 ที่อยู่ (ผู้ขับขี่รถประกัน · ผู้ขับขี่คู่กรณี · ผู้บาดเจ็บ · เจ้าของทรัพย์สิน)

ช่องวิธีกรอก
ที่อยู่ (บ้านเลขที่ / ถนน)พิมพ์บ้านเลขที่ ถนน ซอย เช่น 46/23 หรือ 99 ถ.สุขุมวิท ซ.24 (พิมพ์ "หมู่ที่ 7" ปนมาก็ได้ ระบบแยกให้)
หมู่ตัวเลขอย่างเดียว ไม่บังคับ
จังหวัด → เขต/อำเภอ → ตำบล/แขวงเลือกจากดรอปดาวน์ตามลำดับ (เลือกจังหวัดก่อน อำเภอถึงขึ้น เลือกอำเภอแล้วตำบลถึงขึ้น) กรุงเทพฯ = เขต/แขวง ในลิสต์เดียวกัน
กติกาบังคับ: ไม่รู้ที่อยู่เลย → เว้นว่างทั้งหมด (บอทใส่ - ให้) · กรอกส่วนใดส่วนหนึ่งแล้ว (แม้แค่บ้านเลขที่หรือหมู่) → จังหวัด อำเภอ ตำบล ต้องครบ ไม่งั้นทาแดง กั้นส่งงาน/อนุมัติ
ผลที่เข้า EMCS (ระบบประกอบให้): 46/23 ม.7 ต.ท้ายบ้าน อ.เมือง จ.สมุทรปราการ · กรุงเทพ: 99 ถ.สุขุมวิท แขวงบางนา เขตบางนา กรุงเทพฯ

1.5 ทะเบียนรถ

  • พิมพ์ได้ตามป้ายจริง เช่น 83-2668 — EMCS ไม่รับขีด/เครื่องหมาย/คำพ่วง บอทตัดให้เองเป็น 832668 (เว็บทาแดงและบอกค่าที่จะกรอกไว้ให้เห็น ไม่กั้นอนุมัติ)
  • ไม่มีทะเบียน (คู่กรณีหลบหนี / บุคคลภายนอกรถ) → 00

1.6 เลขบัตรประชาชน

  • บัตรไทย 13 หลัก ต้องผ่านหลักตรวจสอบ (แอป/เว็บเตือนทันทีถ้าเลขผิด) — EMCS ปัดตกทั้งบล็อกถ้าเลขผิด
  • ไม่มีบัตร → - · พาสปอร์ต/บัตรต่างชาติ → เลือกชนิดบัตร "ต่างชาติ/พาสปอร์ต" แล้วพิมพ์เลขตามบัตร (ตัวอักษร+ตัวเลขได้)
  • ข้อจำกัดของ EMCS: เลขที่เป็นตัวเลขล้วนหรืออักษรอังกฤษล้วนแต่สั้นกว่า 13 ตัว จะถูกปัดตก "จำนวนหลักไม่ครบ" → ใช้ - แทน

2. คู่กรณี

2.1 มี 3 สถานการณ์

สถานการณ์แอปมือถือเว็บผู้ตรวจสอบ
ไม่มีคู่กรณีปิดสวิตช์ "มีคู่กรณี"ไม่ต้องมีการ์ด (การ์ดว่างถูกตัดตอนบันทึก)
มีคู่กรณีแต่ไม่มีข้อมูล (หลบหนี)เพิ่มการ์ด → ติ๊ก "รอตรวจสอบ"ติ๊ก "รอตรวจสอบ" ที่หัวการ์ด (ป้ายเหลือง)
มีข้อมูลบางส่วนกรอกที่รู้ · เว้นว่างที่ไม่รู้ · แล้วติ๊ก "รอตรวจสอบ" — ระบบเติมเฉพาะช่องที่ว่าง ไม่ทับที่กรอกไว้ (เอาติ๊กออกไม่ล้างค่า)

2.2 ช่องบังคับของคู่กรณี (EMCS บังคับทุกบริษัท)

เจ้าของรถ · ประเภทรถ · ทะเบียน · จังหวัดทะเบียน · มีประกันภัยที่ · เลขกรมธรรม์ · เพศผู้ขับขี่ · วันเกิด · อายุ  (+ ยี่ห้อเมื่อเลือกประเภทรถแล้ว · ที่อยู่ 3 ช่องเมื่อมีที่อยู่)

2.3 ชุดค่าที่ปุ่ม "รอตรวจสอบ" เติมให้ (เติมเฉพาะช่องที่ว่าง)

ทะเบียน / จังหวัด00 / อื่นๆ
ผู้ขับขี่: เพศ / ชื่อชาย / ไม่ทราบชื่อ (ไม่ใส่คำนำหน้า นามสกุล)
วันเกิด / อายุ01/01/2500 / อายุคำนวณจากปีนั้น (ปีนี้ = 69)

2.4 วันเกิด · อายุ · เพศ

  • วันเกิดต้องเป็นวันจริง วว/ดด/ปปปป (พ.ศ.) — 00/00/2569 หรือ - ไม่ผ่าน (งานจาก ISURVEY ที่ส่งมาแบบนี้ เว็บจะทาแดง ให้แก้หรือติ๊กรอตรวจสอบ)
  • ห้ามพิมพ์วันเกิดเป็นปีปัจจุบัน (เช่น 01/01/2569) หรืออายุ 0 แทน "ไม่ทราบ" — เว็บจะเตือนและกั้นอนุมัติ มีปุ่ม "ใช้วันเกิด 01/01/2500" ให้กดแทน (อายุคำนวณเป็น 69 เอง) · ถ้าหลุดไปถึงบอท/ไฟล์ XML ระบบจะแปลงเป็น 01/01/2500 + 69 ให้
  • แก้วันเกิดแล้วอายุคำนวณให้เอง · อายุต่างจากวันเกิดเกิน 1 ปี เว็บเตือนพร้อมปุ่ม "ใช้ N" และกั้นอนุมัติ
  • เพศบังคับ (ทั้งเว็บ/แอป) — ว่างแล้วบอทจะหยุดรอที่ EMCS

2.5 อื่น ๆ

  • เลขกรมธรรม์/เลขเคลมคู่กรณีที่ช่างพิมพ์เป็นศูนย์ล้วน (0 / 00 / 000000) = ไม่ทราบ → ระบบใช้ -
  • ยี่ห้อต้องอยู่ในลิสต์ของประเภทรถนั้น (เช่น เก๋งเอเชียเลือก BENZ ไม่ได้) เว็บเตือนพร้อมปุ่มเปลี่ยนประเภทให้
  • รายการความเสียหายของคู่กรณีทุกชิ้นต้องมีระดับ (เบา/กลาง/หนัก/เปลี่ยน)

3. ผู้บาดเจ็บ

3.1 ช่องบังคับ

ประเภทผู้บาดเจ็บ · เพศ · ชื่อ-นามสกุล · เลขบัตร · โรงพยาบาล · อาการบาดเจ็บ  (+ ที่อยู่ 3 ช่องเมื่อมีที่อยู่ · แอปบังคับทะเบียนเมื่อประเภทไม่ใช่บุคคลภายนอกรถ)

ไม่มีปุ่ม "รอตรวจสอบ" — ไม่ทราบให้ใช้ - ในช่องข้อความบังคับ (โรงพยาบาล/อาการ/เลขบัตร) เว้นว่างช่องตัวเลข/วันที่ (อายุ 0 ไม่รับ) · ชื่อไม่ทราบ → เว้นว่าง/พิมพ์ - ระบบกรอก EMCS เป็น "ไม่ทราบชื่อ"

3.2 ประเภทผู้บาดเจ็บ (สำคัญ — บอทเลือกให้เองบน EMCS)

ประเภทความหมายทะเบียนใน EMCS
ผู้ขับขี่ - รถประกันคนขับรถคันที่เอาประกันเติมทะเบียนรถประกันเอง
ผู้โดยสาร - รถประกันคนนั่งในรถประกันเติมทะเบียนรถประกันเอง
ผู้ขับขี่ - รถคู่กรณีคนขับรถคู่กรณีเติมทะเบียนคู่กรณีเอง (หลายคันบอทเลือกคันที่ตรง)
ผู้โดยสาร - รถคู่กรณีคนนั่งในรถคู่กรณีเติมทะเบียนคู่กรณีเอง
บุคคลภายนอกรถคนเดินถนน จักรยาน ฯลฯ00 (ไม่มีรถผูก)

งานที่นำเข้าจาก ISURVEY ตรง (ไม่ผ่านเว็บ) ระบบเก่ามีรหัสแค่ 3 แบบ แยกฝั่งคู่กรณีไม่ได้ บอทจะหยุดให้เลือกประเภทบนคอนโซล · งานที่ผ่านเว็บ SE Survey หัวหน้าเลือกไว้แล้ว บอทไม่ถาม

3.3 ชื่อ · เลขบัตร · ที่อยู่

  • คำนำหน้า (ช่องแยก) + ชื่อ นามสกุล → EMCS ได้ นาย สมชาย ใจดี · ไม่ทราบชื่อ → EMCS ได้ ไม่ทราบชื่อ · สแกนบัตรในแอปจะเติมคำนำหน้า/ชื่อ/เลขบัตร/ที่อยู่ให้
  • เลขบัตร: ตามข้อ 1.6 (ไม่มี → - · พาสปอร์ตเลือกชนิดบัตร "ต่างชาติ/พาสปอร์ต")
  • ที่อยู่: ตามข้อ 1.4 (5 ช่อง) — ระบบประกอบเป็นข้อความเดียวเข้า EMCS
  • ระดับการบาดเจ็บ: เล็กน้อย / ปานกลาง / สาหัส / ทุพพลภาพ / เสียชีวิต — ค่ารักษา รายได้ วันรักษา เว้นว่างถ้าไม่ทราบ

4. ทรัพย์สินเสียหาย

4.1 ช่องบังคับ

รายการทรัพย์สิน · สาเหตุที่เสียหาย · รายละเอียดความเสียหาย · ชื่อเจ้าของ  (+ ที่อยู่เจ้าของ 3 ช่องเมื่อมีที่อยู่) · ไม่มีปุ่ม "รอตรวจสอบ" ไม่ทราบใช้ - (ชื่อเจ้าของไม่ทราบ → EMCS ได้ "ไม่ทราบชื่อ")

4.2 เจ้าของทรัพย์สิน

  • คำนำหน้าเจ้าของ: ใส่เฉพาะที่เป็นคน (นาย/นาง/…) → EMCS ได้ นาย สมศักดิ์ มั่นคง · เป็นบริษัท/หน่วยงาน (การไฟฟ้า เทศบาล บริษัท) เว้นว่าง
  • ไม่มีช่องเพศเจ้าของ (EMCS ไม่มี)
  • ที่อยู่เจ้าของ: ตามข้อ 1.4 (5 ช่อง) — ระบบประกอบด้วยเว้นวรรคเข้า EMCS
  • โทรศัพท์ / ค่าเสียหายประมาณ: ตัวเลข ไม่ทราบเว้นว่าง

5. ผู้ขับขี่รถประกัน (สรุปสั้น)

  • บังคับ: เพศ · คำนำหน้า · ชื่อ · นามสกุล · วันเกิด (วันจริง) · อายุ · โทร · เลขบัตร · ใบอนุญาตขับขี่เลขที่ (เมื่อมีใบขับขี่) · ที่อยู่: ตำบลบังคับ
  • ไม่ทราบวันเกิด → 01/01/2500 (อายุคำนวณให้เอง 69) · เลขบัตร/ที่อยู่ไม่ทราบ → - · อายุ 0 หรือไม่ตรงวันเกิด เว็บเตือน+กั้นอนุมัติ
  • ประเภทใบขับขี่ไม่บังคับ (EMCS ไม่บังคับ) เลือกไม่ได้ก็ปล่อยว่าง
  • ไม่มีปุ่ม "รอตรวจสอบ" ส่วนนี้ (ปกติต้องมีข้อมูลผู้ขับขี่รถประกันอยู่แล้ว)

7. เช็กลิสต์ก่อนส่งงาน (แอป) / ก่อนอนุมัติ (เว็บ)

  • ไม่มีช่องดอกจันแดงว่าง — แถบบนเว็บต้องขึ้น "ช่องบังคับครบแล้ว" · การ์ดไม่ขึ้น "ยังขาด N ช่อง"
  • ไม่มีคำว่า "รอตรวจสอบ" / "--" ที่พิมพ์เอง (คู่กรณีใช้ปุ่มติ๊ก)
  • วันเกิด/วันที่ทุกช่องเป็นวันจริง (ไม่ใช่ปีปัจจุบัน) · อายุตรงกับวันเกิดและไม่เป็น 0 · เพศเลือกแล้ว
  • ที่อยู่ที่กรอกบางส่วน มีจังหวัด/อำเภอ/ตำบลครบ
  • ประเภทผู้บาดเจ็บเลือกถูกฝั่ง (รถประกัน / รถคู่กรณี / บุคคลภายนอกรถ)
  • ยี่ห้อรถอยู่ในลิสต์ของประเภทรถ · รายการความเสียหายมีระดับครบ
