คู่มือใช้งาน se-autokey (สำหรับพนักงาน)

บอทกรอกข้อมูลเคลมลง EMCS · ฉบับ 23 กันยายน 2569 · ใช้กับบอท v1.1.37 ขึ้นไป
โปรแกรมนี้กรอกข้อมูลเคลมลง EMCS ให้อัตโนมัติ จาก 2 ต้นทาง แล้วให้คุณ "ตรวจ" และ "กดส่งงาน" ผ่านหน้าเว็บของโปรแกรม
ต้นทางของงานใช้แท็บ
งานที่ตรวจจบบน ISURVEY แล้วนำเข้า ISURVEY
งานที่หัวหน้าอนุมัติบนเว็บ SE Surveyนำเข้า SE Survey
แท็บ "ดึงงานรอตรวจ" เป็นของหัวหน้า — ดึงงาน ISURVEY ที่ยังไม่ตรวจเข้าเว็บ SE Survey ไม่แตะ EMCS

ติดตั้งครั้งแรกจาก USB — ทำครั้งเดียวต่อเครื่อง

  1. ติดตั้ง Google Chrome (ถ้ายังไม่มี)
  2. เสียบ USB → ก๊อปโฟลเดอร์ se-autokey-update ทั้งโฟลเดอร์ ไปวางที่หน้าจอ Desktop ของเครื่องคุณ
  3. เปลี่ยนชื่อโฟลเดอร์ที่เพิ่งวาง se-autokey-update → se-autokey
    ห้ามกด update-here.bat ตอนติดตั้งครั้งแรก — ตัวนั้นใช้ "อัปเดต" เครื่องที่มีโปรแกรมอยู่แล้วเท่านั้น เครื่องใหม่จะขึ้นว่า "ไม่ใช่ se-autokey" แล้วหยุด
  4. เปิดโฟลเดอร์ se-autokey → ดับเบิลคลิก start-webui.bat (หน้าเว็บจะเปิดขึ้นเอง)
  5. ตั้งบัญชีของคุณ — ที่หน้าเว็บ กดแท็บ ตั้งค่า
    • บัญชี ISURVEY → ใส่ชื่อผู้ใช้ + รหัส → กด บันทึกและทดสอบเข้าสู่ระบบ
    • บัญชี EMCS → ใส่ชื่อผู้ใช้ + รหัส → กด บันทึก
    ใช้บัญชีของตัวเองเท่านั้น ห้ามใช้บัญชีร่วมกับคนอื่น (EMCS ล็อกเรื่องตามชื่อผู้ใช้ — ใช้ซ้ำกันจะแย่งเรื่องกันเอง)
    ตั้งครั้งเดียวพอ เครื่องจำไว้ให้ · เว้นช่องรหัสว่าง = แก้แค่ชื่อผู้ใช้
  6. ในแท็บตั้งค่าเดียวกัน เลื่อนลงมาอีก 2 การ์ด → ใส่ค่าที่ผู้ดูแลให้มา (ทุกเครื่องใช้ค่าเดียวกัน ไม่ใช่บัญชีส่วนตัว)
    การ์ดถ้าไม่ใส่
    รหัสแจ้งกลับ ISURVEYส่งงานเข้า EMCS ได้ แต่ ISURVEY ไม่ถูกติ๊กว่าคีย์แล้ว → เสี่ยงคนอื่นมาคีย์ซ้ำ
    ทะเบียนงานคีย์กลาง (se-key)งานที่ส่งแล้วจะไม่ขึ้นทะเบียนที่ key.sesurvey.cloud · กด ทดสอบเชื่อมต่อ ได้เลย ปลอดภัย (แค่อ่าน)

ไม่ต้องลง Python (มีมาให้ในโฟลเดอร์แล้ว) · ไม่ต้องรัน setup ใด ๆ — ดับเบิลคลิก start-webui.bat ได้เลย · ครั้งแรกที่รัน โปรแกรมจะโหลดตัวเชื่อม Chrome ให้เองสักครู่ ขอแค่มีเน็ต

อัปเดตโปรแกรม

ทางปกติ — ผ่านเน็ต ไม่ต้องใช้ USB

  1. หน้าเว็บของโปรแกรม → แท็บ ตั้งค่า → กด ตรวจอัปเดต
  2. ถ้ามีเวอร์ชันใหม่ กด อัปเดตและรีสตาร์ต → รอสักครู่ หน้าเว็บกลับมาเอง
กดตอนไม่มีงานกำลังรันเท่านั้น · ประวัติงาน / รหัสผ่าน / รูปเคส ในเครื่องคุณไม่หาย

ใช้ USB เฉพาะเครื่องที่ยังไม่มีปุ่ม "ตรวจอัปเดต" (เวอร์ชันเก่ามาก)

  1. เสียบ USB → เปิดโฟลเดอร์ se-autokey-update
  2. ดับเบิลคลิก update-here.bat → พิมพ์ y แล้วกด Enter
  3. ปิดหน้าต่างสีดำของ se-autokey ที่เปิดค้างอยู่ (ถ้ามี) แล้วดับเบิลคลิก start-webui.bat ใหม่ — ไม่ปิด-เปิดใหม่ จะยังเห็นหน้าเว็บเวอร์ชันเก่า

ใช้งานทุกวัน — งานที่ตรวจจบบน ISURVEY (แท็บ "นำเข้า ISURVEY")

  1. ดับเบิลคลิก start-webui.bat (หน้าเว็บจะเปิดขึ้นเอง)
  2. เลือกงานได้ 2 แบบ
    แบบทำอย่างไร
    ก) จากรายการ "งานจบแล้ว (ISURVEY)"เลือกช่วงวัน (วันนี้ / 3 วัน / 7 วัน) → กด ดึงข้อมูล → ช่อง "เลขท้าย" ใส่เลขท้ายเลขเคลมที่คุณรับผิดชอบ (เช่น 0,1) → ติ๊กงานที่จะทำ → กด นำเข้าที่เลือก
    ข) พิมพ์เลขเคลมเองพิมพ์ลงในช่อง (ใส่หลายเคลมได้ บรรทัดละ 1 เลข) → กด รันโปรแกรม
  3. รอสักครู่ — หน้าต่าง Chrome จะเปิดขึ้นมากรอกข้อมูลให้เอง

ใช้งานทุกวัน — งานที่หัวหน้าอนุมัติบนเว็บ SE Survey (แท็บ "นำเข้า SE Survey")

  1. แท็บ นำเข้า SE Survey → กด โหลดรายการ (เคสที่ยังไม่เข้า EMCS ขึ้นก่อน · ค้นด้วยเลขเคส/เลขเซอร์เวย์ หรือกรองตาม "ผู้ตรวจสอบงาน" ได้)
  2. ที่การ์ดเคส เลือกปุ่ม
    ปุ่มผล
    นำเข้า EMCSกรอก + อัปรูป + บันทึก draft แล้วหยุด ให้คุณตรวจก่อนส่ง (แนะนำ)
    นำเข้า EMCS + ส่งงานใหม่นำเข้าแล้วกดส่งให้ทันที ไม่หยุดให้ตรวจ (ส่งแล้วแก้ไม่ได้ · ตรวจกลับแล้วไม่ตรง = ไม่ส่ง)
    หลายเคสติ๊กเลือก → นำเข้าที่เลือก หรือ นำเข้า + ส่งงานใหม่ ที่เลือก
  3. ทางนี้ไม่ถามเลือกรูป — รูปชุดที่หัวหน้าอนุมัติไว้เข้า EMCS ให้ทั้งหมด
  4. งานครั้งที่ 2 ขึ้นไป (ติดตาม/เจรจา) บอทเปิดเรื่องเดิมใน EMCS แล้วเพิ่มครั้งใหม่ ไม่สร้างเรื่องซ้ำ
เคสที่หัวหน้า/คอลเซ็นเตอร์กด "ยกเลิก" (เช่น ลูกค้าไม่เคลม) ไม่ขึ้นในรายการนี้ ไม่ต้องนำเข้า

เมื่อบอทกรอกเสร็จ → ตรวจ แล้วกดส่ง

  1. การ์ดงานบนหน้าเว็บขึ้น "พร้อมส่งงาน" พร้อมปุ่มสีเขียว ส่งงาน + แจ้ง ISURVEY
  2. สลับไปดูหน้าต่าง Chrome ที่เปิดอยู่ → ตรวจข้อมูลให้ถูกต้อง
    ถ้าความเสียหายเกิน 8 รายการ ให้เติมรายการที่เหลือเองก่อน
  3. ประเภทงาน (งานต้น / งานตาม / SESV) ระบบเลือกไว้ให้ตามงาน → ตรวจว่าถูก · งานรวมหลาย invoice ให้ติ๊ก "งานรวม" · งานรวม/SESV ต้องใส่เลข invoice (SEABI) อย่างน้อย 1 เลข
  4. ตรวจเรียบร้อยแล้ว → กลับมาที่หน้าเว็บ กดปุ่ม ส่งงาน + แจ้ง ISURVEY → กดยืนยันอีกครั้ง
ระบบจะกดส่งให้ (งานใหม่ = "ส่งงานใหม่" · งานครั้งที่ 2+ = "ส่งผลงานต่อเนื่อง") + แจ้งกลับ ISURVEY + บันทึกทะเบียน se-key ให้อัตโนมัติ → เสร็จ

สิ่งที่อาจเจอระหว่างทาง

ที่เห็นบนการ์ดความหมาย / ทำอย่างไร
กล่องสีเหลือง "ต้องกรอกข้อมูลเอง: ..."ข้อมูลต้นทางไม่ครบ → ถ้ามีตัวเลือกบนการ์ด เลือกได้เลย · ถ้าไม่มี ไปกรอกช่องนั้นในหน้าต่าง Chrome ให้เรียบร้อย แล้วกดปุ่ม ดำเนินการต่อ ในกล่องเหลืองนั้น
กล่องเลือกรูป "เลือกรูปที่จะอัปโหลดเข้า EMCS" (เฉพาะงานจาก ISURVEY)ติ๊กเฉพาะรูปที่ต้องการนำเข้า (เริ่มต้นติ๊กให้ครบทุกรูปแล้ว) → กด อัปโหลดรูปที่เลือก · รูปที่ไม่ติ๊กจะไม่ถูกอัปโหลด
"ข้าม: มีเรื่องใน EMCS อยู่แล้ว"เคลมนี้เคยเปิดเรื่องไว้แล้ว (กันเปิดซ้ำ)
ไม่อยากส่งงานเรื่องไหนแค่ไม่ต้องกดปุ่มส่ง งานจะถูกเก็บเป็น draft ไว้เฉย ๆ
ดูงานที่เคยทำแท็บ สมุดงาน

ข้อควรระวัง

  • ปุ่ม นำเข้า EMCS / รันโปรแกรม จะไม่กดส่งงานเองจนกว่าคุณจะกดปุ่มส่ง → ตรวจให้ดีก่อนกด (กดส่งแล้วย้อนกลับไม่ได้)
  • ปุ่มที่มีคำว่า "+ ส่งงานใหม่" = ส่งทันทีโดยไม่หยุดให้ตรวจ ใช้เมื่อมั่นใจเท่านั้น
  • ใส่หลายเคลมได้ = กดปุ่มครั้งเดียว บอทไล่กรอกทีละเคลมจนครบในหน้าต่าง Chrome เดียว (ไม่ได้ทำพร้อมกัน)
  • แท็บนำเข้า ISURVEY: ใส่หลายเคลม จะไม่มีปุ่มส่งงานบนการ์ด — ทุกเคลมเก็บเป็น draft ต้องเข้า EMCS ตรวจแล้วกด "ส่งงานใหม่" เองทีละเรื่อง
  • เลิกใช้งาน: ปิดหน้าต่างสีดำ (start-webui)
