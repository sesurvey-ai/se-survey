# คู่มือผู้ตรวจสอบ — ตรวจงานบนเว็บ SE Survey (1 หน้า)

เว็บ: **https://survey.sesurvey.cloud** (เปิดใน Chrome) · ล็อกอินด้วยบัญชีผู้ตรวจของตัวเอง

## ตั้งค่าครั้งแรก (ครั้งเดียว)
1. เมนู **งานรอตรวจ ISURVEY** → **บัญชี ISURVEY ของฉัน** → กรอกชื่อผู้ใช้/รหัสผ่าน ISURVEY ของตัวเอง → บันทึกและทดสอบ
   ใช้ดึงงานเข้ามาตรวจ และตอนอนุมัติระบบจะไปกด "ยืนยันการตรวจสอบ" บน ISURVEY แทนคุณด้วยบัญชีนี้
2. เปลี่ยนรหัสผ่านเว็บจากรหัสตั้งต้น (เมนูโปรไฟล์)
3. **ปิด extension se-billing** ใน Chrome ถ้ายังเปิดอยู่ (มันเขียนตัวเลขทับหน้า ISURVEY และอาจบันทึกทับข้อมูลที่ระบบส่งไป)

## ขั้นตอนต่อ 1 งาน
1. **ดึงงาน** — งานรอตรวจ ISURVEY → เลือกช่วงวันที่ (ค่าเริ่มต้นวันนี้) → **โหลดรายการ** → กด **ดึงเข้า** ที่งาน (หรือ **ดึงทั้งหมด**)
   ดึงเสร็จระบบพาไปหน้าเคสเอง · งานติดตาม/เจรจาครั้งที่ 2+ ระบบดึงครั้งก่อนหน้ามาให้อัตโนมัติ (ข้อมูลหลักมาจากครั้งที่ 1 แก้ได้ที่ครั้งที่ 1)
   *งานจากแอปมือถือไม่ต้องดึง จะโผล่ในรายการเคสเมื่อช่างส่งงาน*
2. **ตรวจข้อมูล** — ไล่ตามช่องที่มี **ดอกจันแดง** ต้องไม่ว่างและไม่ขึ้นกรอบแดง
   สิ่งที่ต้องดูเป็นพิเศษ: ยี่ห้อตรงประเภทรถ · วันที่เป็นวันจริง (ไม่ใช่ 00/00) · เลขบัตร/เลขเคลมคู่กรณี (ไม่ทราบให้เลือก "ไม่มีบริษัทประกันภัย" หรือใส่ "-") · ที่อยู่ผู้ขับขี่ครบ จังหวัด/อำเภอ/ตำบล
3. **ความเสียหาย + รูป** — ตรวจรายการความเสียหายและยอดประเมิน · เปิดดูรูป (หมุนได้ก่อนอนุมัติ) · รายการตรวจสอบ 5 ข้อท้ายหน้า
4. **ค่าบริการ** — กรอกช่อง **ราคาพนักงาน** (จ่ายผู้สำรวจ) และ **ราคาประกัน** (เรียกเก็บประกัน) ระบบแนะนำเรทตามพื้นที่ที่ออกตรวจให้ ติ๊กนอกพื้นที่/นอกเวลาถ้ามี
5. **บันทึก** ระหว่างทำได้ตลอด → เสร็จแล้วกด **อนุมัติ**
   อนุมัติแล้วระบบทำให้เอง: ปิดงานบน ISURVEY (จบงาน + ค่าสำรวจ 2 ฝั่ง) · ส่งยอดเข้า se-billing · เคสถูกล็อก
6. **นำเข้า EMCS** — ที่เครื่องที่มีบอท se-autokey: เปิดหน้าบอท → แท็บ **นำเข้า SE Survey** → เลือกเคสที่อนุมัติแล้ว → นำเข้า
   บอทสร้าง **draft** ให้ตรวจบน EMCS แล้ว**กดส่งเองทุกครั้ง** · งานครั้งที่ 2+ บอทเปิดเรื่องเดิมแล้วเพิ่มครั้งใหม่ ไม่สร้างเรื่องซ้ำ

## ถ้าเจอปัญหา
- **แก้หลังอนุมัติ** — ต้องให้แอดมินปลดล็อก (ยอดถูกถอนจาก se-billing แล้วส่งใหม่ตอนอนุมัติซ้ำ) · ยกเว้นเคสอ้างอิงจาก ISURVEY (ครั้งก่อนหน้า) แก้ได้เลยไม่ต้องปลด
- **บอทหยุดรอ** — บอทเจอช่องที่ EMCS บังคับแต่ไม่มีข้อมูล จะเปิดหน้าต่างให้เลือก/กรอกแล้วไปต่อ · ช่องข้อความที่ไม่มีข้อมูลบอทใส่ "-" ให้แก้ตอนตรวจบน EMCS
- **ปุ่มนำเข้า EMCS ไม่ขึ้น** — เครื่องนั้นไม่มีบอท ให้ใช้เครื่องที่มีบอท หรือรอผู้นำเข้า EMCS
- **บอทเวอร์ชันเก่า** — หน้าบอท → แท็บ **ตั้งค่า** → **ตรวจอัปเดต** → อัปเดตและรีสตาร์ต (กดได้ตอนไม่มีงานรัน)
- ติดอะไรที่ไม่อยู่ในนี้ ให้จดเลขเคส + สิ่งที่เห็น แล้วแจ้งแอดมิน
